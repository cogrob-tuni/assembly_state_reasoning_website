# Project website

This folder is the website for a CogRob project. Replace the starter text in `index.html`, add project media under `media/`, and update `site.json`. The feature section includes a CSS placeholder; replace `.fake-image` with a project image or video. The publication section includes a working copy-citation button from `script.js`.

Set `published` to `true` only when the website is ready to appear on the lab landing page.
